# Earlier automation research — archived scope

This note retains the broader November 1, 2026 research so it is not lost. The active scope is now **free discovery only**; read [free job discovery](free-job-discovery.md) first. Nothing here is authorization to install tools, tailor a resume, track applications, submit forms, or contact anyone.

## Original research question and method

The user wanted to distinguish practical automation from Instagram/X demonstrations across discovery, matching, alerts, tracking, tailoring, drafting and submission. Research used the resume, AI journal, official product documentation, and GitHub source/commit/issue inspection. Stars were not the primary criterion.

The [original evidence appendix](../research/2026-11-01-github-evidence.txt) is retained unchanged. It contains inspected revisions, source paths, recent commits, issue samples, historical advertised prices, and source-access caveats. Its product prices are dated observations, not current purchasing advice.

No repositories were installed or executed. No live integrations, security audits, ranking benchmarks, hiring outcomes, application submissions, messages, or schedules were tested or created. Official documentation establishes documented behavior; code inspection establishes an implementation path; neither establishes end-to-end reliability.

## Practical automation and human review

| Step | Practical assistance discussed | Judgment still needed |
|---|---|---|
| Discovery | Combine employer postings/alerts, filter and remove duplicates. | Freshness, source legitimacy and regional coverage. |
| Matching | Compare requirements with factual resume evidence and explain matches/gaps. | Mandatory versus preferred criteria; unsupported or missing information. |
| Alerts | Notify about new qualifying roles or produce a digest. | Relevance and frequency. |
| Tracking | Store postings, document versions and status/reminder information. | Actual status changes and submission receipts. |
| Tailoring | Select relevant accomplishments and suggest clearer wording. | Every skill, responsibility, metric and exported document. |
| Drafting responses | Draft from an approved factual profile. | Motivation, eligibility, compensation, availability and unfamiliar questions. |
| Submission | Autofill supported forms; some products advertise unattended submission. | Custom questions, uploads, account actions, consent, verification challenges and final accuracy. |

Two separate judgments were recommended: **fit based on demonstrated experience** and **opportunity to learn applied AI**. A learning goal must not turn a requirement for years of production experience into a supported match.

## Cross-cutting limits

- Platform rules matter independently of technical capability. LinkedIn and Indeed restrict unauthorized scraping/automation; slowing a bot does not remove restrictions.
- Public employer APIs help discovery but are not universal job indexes or general candidate submission APIs. Greenhouse's authenticated submission endpoint is distinct from public listing access.
- An apparent click on Submit is not proof of successful receipt.
- Ghost-job scores cannot establish employer intent.
- Self-hosting does not keep data local if a cloud model receives it.
- Free repository code may still need paid model/search/hosting services or ongoing maintenance. No defensible universal cost-per-application figure was established.
- Closed issues do not prove a fix was independently regression-tested; main-branch features may not be in the latest release.
